## 1. API仕様一覧

- ベースURL: `/api/v1/`
- 認証: 特記なきものは **Cookie JWT（IsAuthenticated）** 必須。`AllowAny`=未認証可、`IsAdmin`=運営のみ。

### 1.1 認証・プロフィール（accounts）

| メソッド | パス | 認証 | 概要 |
|---|---|---|---|
| POST | `auth/register/` | AllowAny | 新規ユーザー登録 |
| POST | `auth/login/` | AllowAny | ログイン（JWTをCookie発行） |
| POST | `auth/token/refresh/` | Cookie | リフレッシュトークンでaccess再発行 |
| POST | `auth/logout/` | 認証 | ログアウト（Cookie破棄） |
| GET/PATCH | `users/me/` | 認証 | 自プロフィール取得・更新 |
| GET | `admin/users/` | IsAdmin | ユーザー一覧 |
| GET/PATCH/DELETE | `admin/users/<id>/` | IsAdmin | ユーザー詳細・更新・削除 |

## 2. 認証フロー

```mermaid
sequenceDiagram
  participant FE as Frontend
  participant BE as Backend(DRF)
  participant DB as PostgreSQL

  FE->>BE: POST auth/register (username,email,password,...)
  BE->>DB: User作成
  BE-->>FE: 201 Created

  FE->>BE: POST auth/login (email/username, password)
  BE->>DB: 認証
  BE-->>FE: 200 + Set-Cookie(access 15分 / refresh HttpOnly)

  Note over FE,BE: 以降 access Cookie を自動送信

  FE->>BE: GET users/me (Cookie)
  BE-->>FE: 200 プロフィール

  Note over FE,BE: access 期限切れ時
  FE->>BE: POST auth/token/refresh (refresh Cookie)
  BE->>BE: refresh検証 + ローテーション(新refresh発行)
  BE-->>FE: 200 + 新access Cookie

  FE->>BE: POST auth/logout
  BE-->>FE: 200 + Cookie破棄
```

- access 15分 / refresh はローテーション（`ROTATE_REFRESH_TOKENS=True`）。
- 本番はクロスオリジン: `AUTH_COOKIE_SECURE=True`, `SAMESITE='None'`。
- ログインは email / username 両対応（`@` 有無で判定）。

## 4. 主要処理フロー

### 4.1 レッスン視聴 → 進捗更新
```mermaid
flowchart TD
  A[レッスン視聴] --> B[POST enrollments/me/lessons/&lt;id&gt;/progress]
  B --> C{LessonProgress<br/>enrollment+lesson一意}
  C -->|更新| D[is_completed / watch_time_seconds 更新]
  D --> E[Enrollment.progress_percent 再計算]
  E --> F[必要に応じ SkillPoint / UserBadge 付与]
```

### 4.2 AIチャット（ストリーミング）
```mermaid
flowchart TD
  A[受講者が質問送信] --> B[POST ai/chat]
  B --> C{ChatSession<br/>user+lesson一意 取得/作成}
  C --> D[user メッセージ保存]
  D --> E[レッスンtranscript+履歴でLLM呼出]
  E --> F[ストリーミング応答]
  F --> G[assistant メッセージ保存]
```

### 4.3 AI Vtuber コメント
- `GET ai/lessons/<id>/comments/` で `LessonAIComment.comments`（`[{time_label, text}]`）を取得。
- 動画再生位置に連動して時系列コメントを表示。トークン使用量は `input_tokens/output_tokens` に記録。
